## ✨ Description

Welcome to the **Quantum Matrix Red theme designs** – a bespoke, retro-future developer portfolio for Moe Kyaw Aung, a Senior Android & Full-Stack Engineer from Tachileik to Bangkok. This interactive experience is meticulously crafted with a synthwave 1986 aesthetic, featuring neon grids, chrome typography, interactive data cartridges, and an arcade synth assistant.

Dive into a digital universe where code meets culture, and every interaction is a journey through a vibrant, pixel-infused landscape. Explore projects as quantum nodes, consult an AI orb for architectural decisions, and navigate a career timeline that collapses into shipped work. This portfolio is not just a showcase of skills; it's a statement of passion for high-performance mobile engineering and retro-cyber aesthetics.

## 🚀 Features

*   **Dynamic Synthwave Environment** 🌌: Animated starfields, neon particles, a stunning retro sunset, and a 3D wireframe perspective grid create an immersive backdrop.
*   **Global CRT Effects** 📺: Toggleable CRT scanlines, flicker, and curved TV vignette for an authentic 80s feel.
*   **Interactive Navigation Console** 🎮: A fixed header console with quick access to sections and system controls.
*   **Retro Data Cartridges (Project Showcase)** 💾: Slide-in rack of project cartridges, each loadable to reveal ROM specs, memory size, features, and direct GitHub repository links.
*   **80s Arcade AI Copilot (Decision Engine)** 🤖: A floating, interactive AI orb visualizing architectural decisions through implosions, particle bursts, and qubit decoherence. Users can force evaluations.
*   **Pilot Dossier & Skill Matrix** 👤: Detailed profile, photo vault, and a cyber skill matrix displaying technical arsenal with arcade-style power gauges.
*   **Quantum Node Network** 🌐: Projects are represented as quantum nodes with curved entanglement links, data pulses, and interactive observation shockwaves.
*   **Multilingual Support** 🌍: Seamlessly switch between English, Burmese, and Thai for an inclusive user experience.
*   **Web Audio Synth Sound Effects** 🔊: Authentic 80s arcade sounds for clicks, cartridge insertion, lasers, and system events.
*   **Command Palette (Ctrl/⌘K)** ⌨️: An omnibox for quick navigation, project access, social links, theme/language switching, and AI Orb evaluation.
*   **Quantum Cursor** 🖱️: A custom nucleus dot, lerped tractor ring, and spark trail for desktop users.
*   **Printable Resume** 📄: Generate a one-page field manual summary, stack, trajectory, and credentials, formatted for print or PDF export.
*   **MKA://terminal** 📟: A hidden command-line interface for advanced users to interact with the portfolio system.
*   **Responsive Design** 📱: Optimized for seamless viewing and interaction across various devices.

*   **Navigation** 🧭: Use the **Synthwave Header Console** at the top or the **Command Palette** (Ctrl/⌘K) to jump between sections like "START," "CARTRIDGES," "RAD-BOT," "CHIPSET," and "RADIO."

*   **Sound Toggle** 🔊: Enjoy authentic 80s arcade sound effects by toggling the "SYNTH: ON/OFF" button in the top navigation.
*   **Terminal Interface** 📟: Press the `` ` `` (backtick) key to open the hidden MKA://terminal for command-line interactions (e.g., `help`, `whoami`, `projects`, `theme <name>`, `lang <code>`).
*   **Profile & Skills** 🧑‍💻: Explore the "OPERATOR LOG" for a detailed bio and the "NEON CHIPSET MATRIX" for a visual breakdown of technical skills and certifications.

## 📞 API Reference

While this is primarily a frontend portfolio, the application uses custom events for inter-component communication, which can be thought of as an internal API:

*   `window.dispatchEvent(new Event('mka:booted'))`: Triggered when the initial boot loader completes.
*   `window.dispatchEvent(new CustomEvent('mka:evaluate'))`: Forces the AI Orb to evaluate a new architectural decision.
*   `window.dispatchEvent(new CustomEvent('mka:select-project', { detail: projectId }))`: Selects a specific project in the Quantum Node Network.
*   `window.dispatchEvent(new Event('mka:terminal'))`: Opens the terminal interface.
*   `window.dispatchEvent(new CustomEvent('mka:toast', { detail: message }))`: Displays a toast notification with the given message.
*   `window.dispatchEvent(new CustomEvent('mka:lang', { detail: langCode }))`: Changes the application language (e.g., 'en', 'mm', 'th').
*   `window.dispatchEvent(new CustomEvent('mka:sound', { detail: boolean }))`: Toggles sound effects.
*   `window.dispatchEvent(new CustomEvent('mka:power', { detail: boolean }))`: Toggles low-power mode.
*   `window.dispatchEvent(new CustomEvent('mka:theme', { detail: themeName }))`: Changes the application theme.
